## Phase Goal

**As a** recruiter evaluating the live demo, **I want to** watch the agent discover and call a real tool from a companion MCP server — with the call appearing in the reasoning trace exactly like a native tool — **so that** I see concrete evidence of Model Context Protocol integration, and the demo still works cleanly when MCP is switched off.

**This plan's slice:** the tool provider itself. Add the two MCP dependencies (behind a package-legitimacy gate) and build the companion `fetch_url` MCP tool, hardened against SSRF, DoS, and prompt injection from the first commit. After this plan the tool *exists and is unit-safe*; Plan 05-02 makes it reachable over HTTP, and Plans 05-03/05-04 let the agent discover and invoke it.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model/user → `fetch_url(url)` → outbound httpx GET | a model- or prompt-injection-controlled URL crosses into an outbound HTTP request (SSRF surface) |
| fetched third-party page → tool observation → LLM context | untrusted remote content re-enters the agent's prompt |
| PyPI → installed packages | supply-chain: two new dependencies enter the build |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Elevation of Privilege / Information Disclosure (SSRF) | `fetch_url` URL → outbound GET | high | mitigate | scheme allowlist (http/https only) + block `localhost` and any hostname resolving to private/loopback/link-local/reserved IP (blocks 127.*, 10.*, 172.16-31.*, 192.168.*, 169.254.* metadata); re-check host after redirects; unit-tested per blocked range |
| T-05-02 | Tampering (prompt injection via fetched content) | fetched page text → LLM context | high | mitigate | wrap output in `--- BEGIN/END FETCHED PAGE ---` delimiters + SYSTEM_PROMPT untrusted-content instruction (mirrors RAG-09 barrier); optional `strip_invisible` |
| T-05-03 | Denial of Service (huge response) | `fetch_url` response body | medium | mitigate | `MAX_FETCH_BYTES` slice + `MAX_RETURNED_CHARS` truncation + httpx `timeout=10` |
| T-05-04 | Information Disclosure (error/stack leakage) | `fetch_url` exception path | low | mitigate | catch-all returns `Error: {type}: {exc}` string, never raises; global `redact_secrets` still scrubs logs |
| T-05-SC | Tampering | npm/pip installs (`langchain-mcp-adapters`, `mcp`) | high | mitigate | blocking-human legitimacy checkpoint (Task 1) before install; explicit `mcp<2.0.0` pin; no `fastmcp` package |
</threat_model>
